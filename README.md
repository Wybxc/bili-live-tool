# Bili Live Tool

Bilibili 直播推流辅助工具。通过 Bilibili API 获取 RTMP/SRT 等协议的推流地址与推流码，方便使用 OBS 等第三方推流软件开播。

[下载最新构建](https://github.com/Wybxc/bili-live-tool/releases/tag/nightly)
